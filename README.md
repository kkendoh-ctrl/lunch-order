# お昼の注文 🍱

職場のお弁当注文を、3タップで取りまとめるWebアプリ。  
個人モード（今日のランチをワンタップ決定）と、みんなでモード（注文係が集約）の2way 構成。

**アプリを開く** → <https://kkendoh-ctrl.github.io/lunch-order/>

## 機能

### 📱 自分用モード
- お気に入りメニュー登録 → ワンタップで「今日のお昼」決定
- ルーレット／前回と違うのに／ランチ統計（直近30日のランキング）
- 履歴 CSV 出力
- データはこの端末のみに保存（オフライン動作）

### 👥 みんなでモード
- 注文係：今日のお弁当メニュー登録 → 受付URL発行 → QRコード表示 → 自動集計
- メンバー：URL を開いて名前と弁当を選ぶだけ
- **写真からメニュー読み取り**：紙のメニューを撮影 → Gemini API が抽出 → ✓選んで一括追加
- 弁当屋テンプレート保存／過去セッション履歴
- 注文時メモ（ご飯少なめ等）／数量制限／自動更新／印刷／CSV出力
- 締切前の通知（要ブラウザ通知許可）

### 🎨 その他
- ダーク／ライト／自動切替
- PWA 対応（ホーム画面に追加可）
- 日本語UI（うらやす市役所 市民スポーツ課向け）

## 🎥 配信予約メーカー（おまけ）

大会の全試合ぶんの YouTube 配信予約を、手作業ではなく API でまとめて作るページ。

**ページを開く** → <https://kkendoh-ctrl.github.io/lunch-order/stream-scheduler.html>

- 試合表から**配信枠を一括作成**（`liveBroadcasts.insert`）
- **サムネイルを全試合に一括設定**（`thumbnails.set`）
- **再生リストを作って自動で追加**（`playlists.insert` / `playlistItems.insert`）
- **リハーサル**（APIを叩かずに内容とクォータ消費量だけ確認）
- **履歴からまとめて削除・失敗分だけ再実行**（`liveBroadcasts.delete`）

予選15試合＋決勝トーナメント4試合＝19試合、といった構成をワンタップで生成し、
開始時刻は間隔から自動計算（日付をまたいでもOK）。JST→UTC の変換も自動です。

### 使うための準備（初回1回だけ）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る
2. 「APIとサービス」→ **YouTube Data API v3** を有効化
3. 「OAuth同意画面」を作り、自分のGoogleアカウントを**テストユーザー**に追加
4. 「認証情報」→ OAuthクライアントID → **ウェブアプリケーション**
5. 承認済みのJavaScript生成元に `https://kkendoh-ctrl.github.io` を追加
6. できたクライアントIDを、ページの⚙設定に貼る

### 注意

- チャンネルで**ライブ配信が有効**になっている必要があります（有効化に24時間かかる場合あり）。
- API のクォータは既定で1日 10,000。配信枠1件=50、サムネ設定=50、再生リスト追加=50 を消費します（19試合フルセットでおよそ 2,900）。
- 開始予定時刻は**未来の時刻**である必要があります。
- カスタムサムネイルにはチャンネルの電話番号確認が必要です。
- クライアントID・試合表・実行履歴はすべて**端末内（localStorage）**にのみ保存されます。

## 初回セットアップ

「みんなでモード」を使うには Google Apps Script のセットアップが1度だけ必要です。

1. Googleドライブで新規スプレッドシート作成
2. 「拡張機能 → Apps Script」を開く
3. このリポジトリの [`gas-backend.gs`](./gas-backend.gs) の中身をコピペ
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」、アクセス権限は **全員** に
5. 表示されたURLをアプリの「設定」タブに貼って保存

「写真からメニュー読み取り」は Gemini API キー（無料枠）を設定タブに登録すると使えます。

## 技術構成

- 単一HTMLファイル（バニラJS / バニラCSS）
- データ永続化：`localStorage`（端末内）
- 集約バックエンド：Google Apps Script + Sheets（任意）
- OCR：Gemini 2.0 Flash API（任意）
- フォント：Yuji Syuku / Shippori Mincho B1 / Zen Kaku Gothic New / DotGothic16
- 外部依存：QRious（QRコード描画用CDN）
