            問使い方

            自分用モード

            お気に入りのメニューを登録しておけば、ボタン1つで今日のお昼を決めます。ルーレット・前回と違うのに切替も可能。

            みんなでモード（注文係）

            今日のお弁当メニューを登録 → 受付を開く → 発行されたURLをチャットに貼る → みんなが選択 → 自動集計。発注書として印刷もできます。

            みんなでモード（注文する人）

            共有されたURLを開いて、名前を入れてお弁当を選ぶだけ。完了です。

            テンプレート

            よく使う弁当屋のメニューをテンプレ保存しておけば、毎回入力不要。注文係画面の📂ボタンから管理できます。

            サーバー接続（初回のみ）

            「みんなで」モードを使うには、Google Apps Scriptを1回だけ設定する必要があります。設定タブの「設定の作り方」を参照。

            設サーバーの作り方

            「みんなで」モードを使うには、Google Apps Script（GAS）を1度だけセットアップします。所要約5分。料金はかかりません。

            1. Googleドライブで「新規」→「Googleスプレッドシート」を作成
            2. メニュー「拡張機能」→「Apps Script」を開く
            3. 同じフォルダの gas-backend.gs の中身を全部コピー＆ペースト
            4. 右上「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
            5. 「アクセスできるユーザー」を 全員 に設定
            6. 表示されたURLをコピー → 設定タブに貼って保存
            ⚠️ 「全員」を選ばないとメンバーが注文できません。重要！

            蔵テンプレート

            鍵Gemini API キーの取り方

            Google の Gemini API は個人利用なら無料枠で十分使えます（1日1500リクエスト）。 所要 約2分。クレジットカード登録は不要です。

            1. aistudio.google.com/app/apikey を開く
            2. Googleアカウントでログイン
            3. 「API キーを作成」ボタンを押す
            4. 新しいプロジェクトを選んで「API キーを Google Cloud プロジェクトで作成」
            5. 表示されたキー（AIza...）をコピー
            6. このアプリの設定タブに貼って「保存する」
            ⚠️ キーは他人に見せないでください。このアプリでは端末内にのみ保存されます。
