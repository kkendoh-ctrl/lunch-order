      設設定

      Google Cloud で作った「ウェブアプリケーション」のクライアントIDを貼ってください。端末内にのみ保存されます。
      🔑
      承認済みのJavaScript生成元に を登録しておく必要があります。

      説使い方

      はじめに1回だけ：APIの準備

      1. Google Cloud Console でプロジェクトを作る
      2. 「APIとサービス」→ YouTube Data API v3 を有効化
      3. 「OAuth同意画面」を作り、自分のアカウントをテストユーザーに追加
      4. 「認証情報」→ OAuthクライアントID →「ウェブアプリケーション」
      5. 承認済みのJavaScript生成元に を追加
      6. できたクライアントIDを、このページの⚙設定に貼る

      毎回の流れ

      1. 大会設定で大会名・日付・タイトル書式・サムネイルを決める
      2. 試合表で試合数を入れて自動生成、必要なら対戦カードと時刻を直す
      3. 実行でログインし、まずリハーサルで確認
      4. 問題なければ一括作成を押す

      PRISM Live から配信する場合

      このページは配信枠を先に作っておくだけで、配信そのものは PRISM Live から行います。

      1. 前日までに、このページで全試合ぶんの配信枠を作る
      2. 「PRISM Live 向けの設定にする」を押してから作ると、テスト配信の一段階がなくなる
      3. 当日、PRISM Live で LIVE → CONNECT から YouTube に接続
      4. 作っておいた配信予定の一覧から、その試合の枠を選ぶ
      5. 配信開始。タイトル・サムネイル・再生リストは設定済みなので、毎回入力しなくていい

      試合ごとに枠を選び直すので、タイトルは一覧で見分けやすい書式にしておくのがおすすめです。

      知っておくこと

      • チャンネルでライブ配信が有効になっている必要があります（有効化に24時間かかる場合あり）。
      • APIの1日のクォータは既定で10,000。配信枠1件あたり50、サムネ設定50、再生リスト追加50を消費します（19試合フルセットでおよそ2,900）。
      • 開始予定時刻は未来の時刻である必要があります。
      • カスタムサムネイルにはチャンネルの電話番号確認が必要です。
      • ログインの有効期限は約1時間です。切れたら再度ログインしてください。
      • 本番前に、まず限定公開で1件だけ作って PRISM から選べるか試してください。
